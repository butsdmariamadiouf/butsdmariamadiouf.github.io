SAÉ 3.01 : Site web dynamique

Contexte

Ce projet consiste à développer une application web permettant de gérer et visualiser des données OpenData.

Objectifs

  • Créer un site web dynamique
  • Connecter une base de données MySQL
  • Afficher des données

Méthodologie

- Conception UML
- Création base de données
- Développement PHP
- Visualisation JS (graphique)

Outils utilisés

HTML / CSS / PHP / MySQL / JavaScript / jQuery

Résultats

L'application permet d’afficher des tableaux et des graphiques interactifs.
