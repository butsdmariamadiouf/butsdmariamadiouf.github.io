SAÉ 4.01 : Automatisation & Programmation Objet

Projet Individuel — GameTracker

Contexte

Dans le cadre de cette SAÉ individuelle de 6 heures, j'ai développé de bout en bout l'application GameTracker pour une startup spécialisée dans l'analyse de performances des joueurs de jeux vidéo. L'enjeu technique résidait dans l'infrastructure, la modélisation et la conteneurisation d'un pipeline complet.

Face à deux jeux de données brutes corrompus (Players.csv et Scores.csv), ma mission consistait à configurer une infrastructure multi-services virtualisée permettant d'extraire, nettoyer, structurer et charger automatiquement ces flux d'informations dans une base relationnelle sécurisée.

Objectifs du projet

Afin de valider cette situation d'évaluation, le projet s'est articulé autour de 3 axes fondamentaux :

Conteneurisation

Orchestrer une infrastructure isolée multi-services (Python 3.11 et MySQL 8.0) via Docker Compose.

Pipeline ETL Robuste

Développer en programmation orientée objet un script Python exploitant Pandas pour assainir et charger les flux.

Automatisation

Concevoir des scripts Bash pour coordonner l'initialisation SQL, les verrous d'attente et le lancement global.

Résolution des 7 Problèmes de Qualité des Données

Le cœur algorithmique du pipeline Python (Pandas) a été codé pour détecter et neutraliser de manière hermétique les anomalies suivantes :

  • Doublons : Suppression des redondances ID clés sur les joueurs et les sessions.
  • Emails invalides : Filtrage de conformité textuelle par absence du caractère obligatoire @ (remplacé par None).
  • Dates incohérentes : Normalisation syntaxique des formats hétérogènes (ISO, FR, chaînes corrompues) via pd.to_datetime(errors='coerce').
  • Espaces parasites : Nettoyage systématique (strip) des chaînes textuelles des pseudonymes.
  • Scores aberrants : Exclusion logique stricte de tous les scores négatifs ou nuls.
  • Valeurs manquantes : Conversion et typage propre des cellules vides de Pandas (NaN/NaT) vers le format natif None accepté par MySQL.
  • Références orphelines : Résolution de l'intégrité référentielle en éliminant les scores liés à un identifiant joueur inexistant dans la table parent.

Architecture de la Méthodologie ETL

Le déploiement respecte une structure modulaire stricte, jalonnée par les étapes de production suivantes :

1

Infrastructure Multi-Services (Docker & Compose)

  • Configuration d'une image applicative optimisée python:3.11-slim embarquant les dépendances métiers.
  • Paramétrage du service de base de données sous MySQL 8.0 doté d'un processus de healthcheck et de volumes persistants.
2

Sécurisation de Connexion & Scripts d'Attente

  • Implémentation du script Bash wait-for-db.sh bloquant l'application tant que le serveur SQL n'est pas opérationnel (30 tentatives max, intervalle de 2s).
  • Développement d'un Context Manager en Python gérant de façon transparente les Commits, les Rollbacks en cas d'échec et la fermeture des sessions.
3

Développement Algorithmique du Pipeline Python

  • Extract : Extraction des fichiers plats CSV sécurisée par vérification d'existence des chemins d'accès.
  • Transform : Application séquentielle des règles d'assainissement de données et transmission des clés valides parentes au sous-module des scores.
  • Load : Injection SQL optimisée par requêtes préparées couplées à l'instruction ON DUPLICATE KEY UPDATE pour prévenir les collisions d'index.

Apprentissages Critiques Validés

Cette réalisation en autonomie complète a permis de valider les compétences et jalons critiques suivants :

AC | Virtualisation et Isolation d'environnements de Data Science

Conteneurisation complète d'une pile applicative. Maîtrise des concepts de variables d'environnement, de cycle de vie de conteneur imbriqué (healthcheck) et de persistance des bases par montage de volumes.

AC | Conception de Pipelines de Données Structurés et Robustes

Création d'un code Python orienté objet hautement modulaire (séparation stricte Extract/Transform/Load). Résolution mathématique des anomalies et intégrités de BDD.

AC | Automatisation Industrielle et Intégration Continue

Écriture de scripts shell Bash pour orchestrer l'intégralité d'un processus sans intervention humaine, assurant une reproductibilité parfaite et une gestion saine des codes d'erreur de sortie.
